# aTES — UberPopug Inc Task Exchange

Общий язык для всех сервисов Awesome Task Exchange System.

## Участники

**Попуг (Popug)**:
Сотрудник UberPopug Inc — создаёт и выполняет задачи. Имеет роль и счёт.
В коде и схемах — `Popug`. В REST для совместимости — `user`.
_Избегать_: User (в домене), Employee, Сотрудник

**Роль (Role)**:
Уровень доступа попуга: `popug` (исполнитель), `manager` (управленец),
`accountant` (бухгалтер), `admin` (администратор).
_Избегать_: AccessLevel, Permission

## Задачи

**Задача (Task)**:
Единица работы с описанием, статусом, исполнителем и ценами.
_Избегать_: Ticket, Issue, WorkItem

**Ассайн (Assignment)**:
Назначение задачи на конкретного попуга-исполнителя. Бывает первичным
(при создании задачи) и повторным (при реассайне). При ассайне со счёта
попуга списывается AssignFee.
_Избегать_: Назначение, Allocation, Delegation

**Реассайн (Reassignment)**:
Массовое перераспределение всех открытых задач между попугами. Инициируется
админом или менеджером. Старому исполнителю возвращается AssignFee,
с нового — списывается.
_Избегать_: Shuffle (REST-название операции, не доменный термин)

**Статус задачи (TaskStatus)**:
`open` — задача открыта и ожидает выполнения. `completed` — задача выполнена.
Переход только open → completed. Обратный переход не предусмотрен.
_Избегать_: done, closed, resolved

## Финансы

**Счёт (Account)**:
Финансовый счёт попуга. Содержит баланс и историю операций (аудитлог).
Создаётся при регистрации попуга.
_Избегать_: Balance (поле счёта), Wallet

**Баланс (Balance)**:
Текущая сумма на счёте, в долларах. Может быть отрицательной.
Отрицательный баланс переносится на следующий день.
_Избегать_: Amount

**Стоимость ассайна (AssignFee)**:
Сумма в долларах, списываемая со счёта попуга при ассайне на него задачи.
Генерируется однократно при создании задачи: rand(10..20)\$.
_Избегать_: AssignmentCost, DebitFee

**Стоимость выполнения (CompleteReward)**:
Сумма в долларах, начисляемая на счёт попуга при выполнении задачи.
Генерируется однократно при создании задачи: rand(20..40)\$.
_Избегать_: CompletionBonus, CreditReward

**Доход менеджмента (ManagementEarnings)**:
Прибыль компании за день: sum(AssignFee) − sum(CompleteReward).
Может быть отрицательным.
_Избегать_: CompanyProfit, TopManagementEarnings

**Выплата (Payout)**:
Операция в конце дня: расчёт итогового баланса попуга, обнуление счёта,
запись в аудитлог. Если баланс отрицательный — выплата = 0, долг переносится.
_Избегать_: Payment

**Аудитлог (AuditLog)**:
Хронологическая запись всех финансовых операций по счёту. Каждая запись
содержит: тип операции (assign, complete, refund, payout), сумму, id задачи
и человекочитаемое описание.
_Избегать_: TransactionLog, History
