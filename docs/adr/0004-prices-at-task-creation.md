# Цены задачи генерируются при создании

assignFee и completeReward генерируются один раз в момент создания задачи
и фиксируются в событии TaskCreated. При реассайне используется та же assignFee —
сумма возврата равна сумме списания.

Причина:
- Бизнес-требование: «цены определяются единоразово, в момент появления
  в системе».
- Упрощает реассайн: не нужно заново генерировать assignFee и хранить
  исторические значения.
- Гарантирует, что сумма возврата при реассайне равна сумме первоначального
  списания (нет расхождения из-за повторной рандомизации).

Альтернатива: генерация assignFee при каждом ассайне заново. Отвергнута —
противоречит требованию единоразовости, усложняет возврат при реассайне.
